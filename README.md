# PokeApi

## Tecnologías utilizadas

* **React** (Hooks: `useState`, `useEffect`)
* **JavaScript**
* **CSS en línea**
* **Consumo de API**

## Requisitos previos

Antes de comenzar, necesitas tener instalado:
* **Node.js**.

## Ejecución local
Sigue estos pasos en tu terminal para correr el proyecto:

1. **Clona este repositorio**:
   ```bash
   git clone [https://github.com/brandonAS09/PokeAPI.git](https://github.com/brandonAS09/PokeAPI.git)


###Entra a la carpeta del proyecto:
```Bash
cd PokeAPI
```
Instala las dependencias:
```Bash
npm install
```

Inicia el proyecto:
```Bash
npm run dev
